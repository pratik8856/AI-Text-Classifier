# AI Text Classifier

## Description

This project classifies user text into categories such as:

- Greeting
- Question
- Complaint
- Feedback

## Technologies Used

- Python
- Pandas
- Scikit-learn

## How to Run

```bash
pip install -r requirements.txt
python classifier.py
```

## Example

Input:

Hello

Output:

Greeting
